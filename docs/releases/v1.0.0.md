# RepoPlane v1.0.0

RepoPlane v1.0.0 is the first stable release of a repository control-plane MCP server built for
coding agents that need bounded evidence instead of unqualified guesses or whole-workspace dumps.

## Highlights

- Five read-first tools cover capability discovery, repository search, path facts, structured data,
  and durable records with explicit scope, pagination, and partial-state semantics.
- Git history, configured symbol indexes, Markdown frontmatter, JSON/JSONL, logs, CSV, TSV, UTF-8,
  CP949, and strict EUC-KR are handled without collapsing missing or unknown results into empty
  success.
- Checkpoints, memos, imported verification, environment observations, run receipts, and artifact
  evidence survive client restarts in a separate local `records.db`.
- The opt-in Runner executes only catalog-registered, host-trusted capabilities through
  prepare/execute/inspect; it never accepts an arbitrary executable or shell string from MCP input.
- Optional authenticated Streamable HTTP adds per-tool scopes, Origin/Host gates, rate and
  concurrency limits, cancellation, and a separate redacted audit store.
- Exact record field projection and compact mutation receipts reduce repeated context while the
  complete typed 11-tool contract remains available.

## What ships

The default stdio server exposes `catalog_query`, `workspace_search`, `path_explain`, `data_query`,
and `project_records`. Hosts can independently enable checkpoint/memo writes, verification-report
import, Runner, and qualification-gated cache reuse. No opt-in is enabled by installing the binary.

## Safety model

Workspace traversal checks reject lexical, symlink, and Windows junction escapes. Reads, result
counts, command output, artifacts, deadlines, and retained state are bounded. Secrets and local
paths are excluded from public diagnostics; HTTP authentication, Runner execution, and cache reuse
remain fail-closed behind separate host and request-level gates.

## Install or upgrade

Download the Windows or Linux amd64 archive and `SHA256SUMS.txt` from this release, verify the
archive hash, and place the extracted binary on `PATH`. Install `rg`; install Git only when Git
history search is needed. Configure an external `--state-dir`, restart the MCP client, and enable
write, import, Runner, cache, or HTTP flags only when required. On Windows, rotate an in-use prior
binary to `old_repoplane_<timestamp>.exe` before copying the replacement.

## Compatibility

This release supports Windows amd64 and Linux amd64 with Go 1.26-era builds. Existing v1 SQLite
records and additive schema migrations remain readable. stdio and the five read tools stay the
default. This is the first versioned release, so there is no earlier stable API line to migrate.

## Verification

The tagged commit passed the repository schema/test/vet/build workflow on Windows and Ubuntu plus
the Linux race suite. The tracked tree and reachable Git history passed the public privacy gate.
Asset filenames, archive contents, target binaries, injected version, and SHA-256 values are checked
before publication.

## Known limits

Semantic/vector search, arbitrary source-language parsing, XML, JSONPath/JMESPath, arbitrary shell
execution, automatic secret redaction of captured command output, and built-in disaster-recovery
backup are not provided. Symbol search requires a configured index. Local durable state still needs
an encrypted external backup to survive disk loss or machine reset.
