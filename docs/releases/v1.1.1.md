# RepoPlane v1.1.1

RepoPlane v1.1.1 makes Go verification failures easier to locate without exposing host paths and
publishes an implementation-ready design for evaluating a smaller, stable MCP discovery surface.
The runtime server contract remains unchanged from v1.1.0.

## Highlights

- Distinguish the configured Go build workspace from the generic operating-system temporary
  directory in sanitized verification diagnostics.
- Label paths beneath `GOTMPDIR` as `GO_TMP`, preserving privacy while making antivirus and
  toolchain failures actionable.
- Document an opt-in five-toolbox design with lazy per-operation contracts and content-bound schema
  handles.
- Define staged implementation, security-parity, compaction, prompt-cache, and measured A/B gates
  before any toolbox surface can replace the current default.

## What ships

The Windows and Linux amd64 archives continue to provide the same 14 typed MCP tools and external
request/response contracts as v1.1.0. The source release updates the developer verification
diagnostic sanitizer and adds the lazy-toolbox specification and implementation plan. The toolbox
surface is not implemented or enabled in these archives.

## Safety model

Diagnostic sanitization still removes workspace, temporary, and user-home absolute paths. The new
`GO_TMP` marker identifies only the path class and does not reveal the configured directory.

The toolbox proposal preserves the five existing authorization classes, operation-specific strict
Go decoding, approval and audit behavior. It explicitly rejects runtime profile promotion and
mutable tool discovery; schema handles identify contracts but do not prove authorization, approval,
freshness, or model-context residency.

## Install or upgrade

Download the Windows or Linux amd64 archive and `SHA256SUMS.txt`, verify the archive hash, and
replace the existing `repoplane` binary on `PATH`. Restart the MCP client so it loads v1.1.1 and
inherits current host environment settings; already-running MCP processes keep their loaded binary
and environment.

## Compatibility

This patch supports Windows amd64 and Linux amd64. It does not add, remove, rename, or merge MCP
tools and does not change durable schemas or require a state migration. Existing v1.1.0 client and
server configuration remains valid.

## Verification

The tag commit is required to pass generated-schema drift, fresh package tests, vet/build, the
tracked-tree and complete reachable-history privacy scan, Windows and Ubuntu verification, and the
Linux race job. Release archives are built with `-trimpath`, embed `v1.1.1`, and are checked against
the published lowercase SHA-256 checksum file before and after publication.

## Known limits

The five-toolbox surface remains a design and measurement plan, not a runtime feature. The current
14 typed tools are still exposed eagerly. `GO_TMP` improves diagnostic classification but does not
change antivirus policy or prevent a host security product from blocking a transient Go test
executable.
